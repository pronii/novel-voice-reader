# MiMo V2.5 TTS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Xiaomi MiMo V2.5 TTS with secure credentials, preset voices, natural-language narration style, connection testing, caching, and existing precise playback speed support.

**Architecture:** Extend the existing `VoiceProfile` and `SpeechProviderFactory` switch with a dedicated MiMo client. Keep credentials in `SecureCredentials`, expose configuration through `VoiceSettingsPage`, and wire test/save behavior in the router using the same boundaries as Zhipu and Tencent.

**Tech Stack:** Flutter, Dart, Dio, flutter_secure_storage, flutter_test, just_audio

## Global Constraints

- Use `https://api.xiaomimimo.com/v1/chat/completions` and `mimo-v2.5-tts`.
- Support only the eight official preset voices in this release.
- Never persist or log the MiMo API Key outside secure storage.
- Preserve player-side exact playback speeds from 0.5x through 2.0x.
- Follow RED, GREEN, REFACTOR for every production behavior.
