# 移动端实机验证矩阵

自动化基线：Flutter 3.44.8、Dart 3.12.2；Windows 已通过 `flutter test`、`flutter analyze` 和 Android debug APK 构建。

| 场景 | Android | iPhone | 备注 |
|---|---|---|---|
| TXT/EPUB 导入 | 待实机 | 待实机 | 包含中文编码与非 DRM EPUB |
| 系统 TTS | 待实机 | 待实机 | 检查语速、暂停、继续 |
| 云端 TTS | 待实机 | 待实机 | 使用测试端点，不记录正文或 Key |
| 锁屏控制 | 待实机 | 待实机 | 播放、暂停、上一段、下一段 |
| 来电/音频焦点中断 | 待实机 | 待实机 | 中断后保持已确认进度 |
| Wi-Fi 切换蜂窝网络 | 待实机 | 待实机 | Wi-Fi-only 任务不得启动 |
| 缓存容量上限 | 待实机 | 待实机 | 检查停止排队与已完成文件保留 |
| 进程重启恢复 | 待实机 | 待实机 | 恢复最后确认段落 |
| 深色模式与大字体 | 待实机 | 待实机 | 检查无重叠、无裁切 |
