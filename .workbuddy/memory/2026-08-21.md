# 2026-08-21 — 阅读页听书按钮与翻页模式改造

## 听书按钮改造

- toolbar 中的"播放"按钮改成 `IconButton.filledTonal`（圆形，带浅色背景），
  tooltip 在 `widget.playbackActive` 时切换为「退出听书」/「听书」，
  图标在 `Icons.headphones` / `Icons.headphones_off` 之间切换。
  该按钮随 toolbar 显隐（默认隐藏），不再常驻遮挡正文。
- 新增 `ReaderPage.onStopPlayback` 回调；router 中 `_stopPlayback()` 调用
  `runtime.handler.stop()` 并本地清空 `_playbackCursor`，让 toolbar 圆形
  按钮和浮动"退出听书"按钮能触发真实停止。
- 新增右下角浮动「退出听书」条 (`Key('reader-exit-playback')`)：仅
  `playbackActive=true && onStopPlayback!=null` 时显示，与 toolbar 无关，
  解决 toolbar 隐藏时无法退出的问题。

## 翻页模式

- `reader_content.dart` 新增 `enum ReaderPageMode { scroll, horizontal, curl }`。
- `_ReaderPageState._pageMode` 默认 `scroll`（保持原长列表 + auto-scroll）。
- 水平/仿真模式共用 `PageView.builder`（每章一页）：
  - `horizontal`: 默认 PageView，左右滑动翻章。
  - `curl`: 包裹 `_PagedPage` 的 `AnimatedBuilder` 监听 PageController
    位置，对当前页应用 `Matrix4.rotateY` + perspective 实现 3D 翻页感。
- `_buildPagedBody` 用 postFrameCallback `jumpToPage(initialPage)`，确保首次
  build 时 PageView 已 attached。
- 阅读设置底部新增 `SegmentedButton<ReaderPageMode>` 三选一
  (Key `'reader-page-mode-segmented'`)。切换时 setState 并重新 jump。
- 新增辅助类：
  - `_PagedPage(StatelessWidget)`: 单页内容，章节 heading + 段落 + PlayFrom。
  - `_ParagraphTile(StatelessWidget)`: 替代 scroll mode 中的 inline 渲染，
    统一 playing/active 高亮和 "从这里朗读" 按钮。

## 测试更新

- `tooltip: '播放'` → `tooltip: '听书'` 两处：
  - `disables playback commands while playback is starting`
  - `top play follows the first visible paragraph after scrolling`

## 注意事项

- 默认 `_pageMode` 为 scroll，原有测试 (continuous_reader_page_test 等)
  仍走 ScrollablePositionedList 路径不受影响。
- horizontal/curl 模式共享同一 `_pageViewController`（首次 build 时
  `hasClients=false`，所以 postFrame 中 jumpToPage 才生效）。
- `_jumpToInitialPosition` 现在只在 scroll mode 下做 scroll jump；
  翻页模式的定位由 `_buildPagedBody` 接管。
