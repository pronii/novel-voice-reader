### 工具链踩坑（重要，下次直接照做）
- PATH 里没有 flutter，必须用 `./work/tools/flutter/bin/flutter.bat`。
- **不要同时开两个 flutter 进程**：它们会抢 `.dart_tool` 锁，导致双方都静默卡死
  （表现为日志 0 字节、任务显示 running 但时间戳为负）。一次只跑一个，跑之前
  先确认没有残留的 `dart.exe`。
- `flutter test` 输出经过管道时会缓冲，用 `--reporter expanded` + `tee` 落盘，
  再读日志文件看进度；前台直接跑 + `| tail` 在 Git Bash 下容易拿不到输出。
- 基线：`test/features/reader` 78 个测试全绿（重构前确认过，用时约 1 分钟）。
